# Математика 1514

Статический сайт для GitHub Pages: основные разделы, материалы и юридические страницы `mathnomagic.ru`.

- Главная страница: `index.html`
- Архив: `archive/index.html`
- Общие стили: `assets/styles.css`
- Исходный текст юридических страниц: `pages/*/content.md`
- Скрипты обновления каталога материалов и юридических страниц: `scripts/`

Все PDF собраны в `archive/files/`. После добавления новых PDF список можно пересобрать скриптом `scripts/build-archive.mjs`. Старые адреса обрабатываются централизованно в `404.html`, поэтому для них не нужны отдельные папки в корне.
