# Математика 1514

Статический сайт для GitHub Pages: основные разделы, архив материалов и сохранённые юридические страницы прежнего сайта `mathnomagic.ru`.

- Главная страница: `index.html`
- Архив: `archive/index.html`
- Общие стили: `assets/styles.css`
- Исходный текст юридических страниц: `pages/*/content.md`
- Скрипты обновления архивного каталога и старых адресов: `scripts/`

Все PDF хранятся непосредственно в репозитории. После добавления новых PDF архивный список можно пересобрать скриптом `scripts/build-archive.mjs`.
