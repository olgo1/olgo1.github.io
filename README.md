# Математика 1514

Статический сайт для GitHub Pages: основные разделы, материалы и юридические страницы `mathnomagic.ru`.

- Главная страница: `index.html`
- Архив: `archive/index.html`
- Общие стили: `assets/styles.css`
- Исходный текст юридических страниц: `pages/*/content.md`
- Скрипты обновления каталога материалов и юридических страниц: `scripts/`

Все PDF собраны в `archive/files/`. После добавления новых PDF список можно пересобрать скриптом `scripts/build-archive.mjs`. Старые адреса обрабатываются централизованно в `404.html`, поэтому для них не нужны отдельные папки в корне.

## Обновления сайта

Единый источник записей — `data/updates.json`. Новые записи добавляются с датой публикации в формате `YYYY-MM-DD`; текст и ссылки задаются в `segments`. Старые записи сохраняются.

После изменения списка запустите `node scripts/build-updates.mjs`. Скрипт сортирует записи от новых к старым и формирует:

- на главной странице — не более **трёх последних записей** и ссылку «Все обновления»;
- на странице `/updates/` — **полную историю**, без ограничения количества записей.

Если записей меньше трёх, на главной показываются все имеющиеся. При одинаковой дате сохраняется порядок записей в JSON. Сгенерированный блок главной и страницу `updates/index.html` вручную не редактируют: изменения вносят в JSON, затем пересобирают. Для публикации сохраняют источник, скрипт и обе HTML-страницы.
