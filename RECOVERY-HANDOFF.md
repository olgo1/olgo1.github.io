## На другом компьютере

1. Получите обе recovery-ветки из origin либо клонируйте bundle с явной веткой:
   ~~~text
   git clone --branch recovery/published-2026-11-22 website-reconciliation.bundle restored-website
   ~~~
2. Сначала откройте опубликованную ветку. Затем сравните с локальной:
   ~~~text
   git diff origin/recovery/published-2026-11-22...origin/recovery/local-unpublished-2026-11-22
   git diff origin/recovery/published-2026-11-22 origin/recovery/local-unpublished-2026-11-22
   ~~~
   Первая команда показывает изменения относительно общего предка; вторая — фактическую разницу двух снимков. Различия могут означать и более старую локальную версию.
3. Приватный ZIP распаковывайте отдельно. Скрипты в tmp/output сохранены как исходные материалы, а не как команда к немедленному выполнению. Некоторые из них выполняют публикацию, назначение заданий или обращения к другим сервисам.
4. Для просмотра статического сайта достаточно локального HTTP-сервера; не запускайте publish/deploy без проверки.
5. После выбора нужных изменений подготовьте отдельную обычную рабочую ветку. В этом этапе deploy не разрешён и не нужен.
