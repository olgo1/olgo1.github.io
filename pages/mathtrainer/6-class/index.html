  2. 6.Умножение смешанных чисел. Алгоритмы

    Зачёт — 4 из 4.

    1. Запишите всю цепочку вычислений и получите ответ.

      Умножение обозначайте * или ·, дробь — через /. Смешанное число записывайте через пробел, например 2 3/7. В окончательном ответе выделите целую часть и сократите дробную.

      256·8

    2. Запишите всю цепочку вычислений и получите ответ.

      Умножение обозначайте * или ·, дробь — через /. Смешанное число записывайте через пробел, например 2 3/7. В окончательном ответе выделите целую часть и сократите дробную.

      113·1,25

    3. Как правильно начать решать пример? Запишите номер верного варианта, а затем вычислите результат и запишите ответ.

      347·710
      1. 3+47·710
      2. 3+47·710
      3. 257·710

    4. Как правильно начать решать пример? Запишите номер верного варианта, а затем вычислите результат и запишите ответ.

      3310·1111
      1. 3·1+310·111
      2. 3+310·1+111

  3. 7.Умножение смешанных чисел. Счёт, выражения

    Для зачёта: 2 из 3.

    1. Запишите всю цепочку вычислений и получите ответ. В окончательном ответе выделите целую часть и сократите дробную.

      214·0,8+56·135−1310

    2. Упростите выражение, затем найдите его значение.

      134x+(512x−116),x=1,2.

    3. Какие из произведений являются натуральными числами? Выпишите номера всех подходящих вариантов. Вычислять значения произведений не нужно.

      1)238·82)135·2143)313·0,3
  4. 8.Счёт с помощью распределительного закона

    Для зачёта: 3 из 3.

    1. Вычислите удобным способом (вынося за скобку общий множитель).

      3111·134+3111·11112

    2. Вычислите удобным способом.

      25·534−25−25·278

    3. Перейдите от деления к умножению, после этого вынесите общий множитель за скобку и вычислите.

      67·813−434:116
  5. 9.Умножение смешанных чисел. Задания посложнее

    Для зачёта: 2 из 3.

    1. Решите уравнение.

      314−(x−56):112=2512.

    2. Упростите выражение и найдите его значение.

      213x−x:115,x=159.

    3. Решите задачу.

      Скорость лодки по течению реки равна 12811 км/ч, а против течения — 9811 км/ч. Сколько километров проплывёт плот по этой реке за 123 ч?

      Ответ запишите в километрах.
