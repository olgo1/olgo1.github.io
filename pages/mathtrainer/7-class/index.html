Модуль 2. Многочлены. Раскрытие скобок

  1. 1.Одночлены. Умножение, деление и возведение одночленов в степень.

    Зачёт — 3 из 4.

    1. Упростите выражение:

      −13p3·(−18k)·7pk4.

      Запишите одночлен стандартного вида.

    2. Произведение двух одночленов равно −6,4x7y7. Первый множитель равен 4x3y2. Найдите второй множитель.

    3. Чему равно частное квадрата одночлена (−16p2k2) и одночлена −5p2k?

      Запишите ответ одночленом стандартного вида.

    4. Вася перемножил одночлены 2x4y3 и −2x3y3. Петя перемножил два других одночлена и получил такое же произведение.

      Каких из перечисленных одночленов точно не могло быть среди множителей Пети? Запишите в ответ их номера. Выберите все подходящие варианты.

      1. −3xy5
      2. 4xy3
      3. −12x8y4
  2. 2.Одночлены-2. Представить одночлен в виде степени или произведения степеней.

    Зачёт — 3 из 3.

    1. Какой одночлен нужно возвести в квадрат, чтобы получить

      169x8y4?

    2. Одночлен m44k8 представили в виде степени другого одночлена. Каков наибольший возможный натуральный показатель этой степени?

      Запишите только показатель.

    3. Выберите все одночлены, которые нельзя представить ни в виде квадрата, ни в виде куба другого одночлена:

      1. x2y15z8
      2. a12b18
      3. m42

      Запишите номера всех подходящих вариантов.

  3. 3.Стандартный вид многочлена. Привести подобные слагаемые, найти значение многочлена.

    Зачёт — 3 из 3.

    1. Приведите подобные слагаемые и запишите многочлен стандартного вида:

      k2+14km2−k2+16−8km.

    2. Приведите подобные слагаемые и найдите значение многочлена

      xy−256xy2+23xy2+112xy2−123xy

      при x=1,5, y=−3.

      Запишите только значение многочлена.

    3. Выберите номера многочленов, в которых можно привести подобные слагаемые.

      1. −1,2k3−1,2k3+0,4k3−0,6km2+2,7km2
      2. −2,1a2+1,7b+2,8a3+2,5b3
      3. 1,7y−0,8y3+0,8x−2,1y3
      4. −2,1m+1,1n+0,9+1,9−1,5m
      5. 2,6m3+2,9mn−1,9m3+0,1m3+2,2n2

      Запишите номера всех подходящих вариантов.

  4. 4.Сложение и вычитание многочленов. Упростить выражение со скобками, найти значение, решить уравнение.

    Зачёт — 3 из 3.

    1. Упростите выражение:

      (−9km−2k)+(4km+4m3).

    2. Решите уравнение:

      7m2−(m2+8m)=0.

      Запишите оба корня этого уравнения.

    3. Вместо звёздочки запишите такой многочлен, чтобы получилось тождество:

      (14m5+11m3+2m2)−(*)=6m3−13.
  5. 5.Сложение и вычитание многочленов. Повышенная сложность.

    Зачёт — 3 из 3.

    1. На какое наибольшее натуральное число делится без остатка значение выражения

      (−5x+10y)−(−14x−17y)

      при любых натуральных x и y?

    2. Расставьте скобки так, чтобы равенство стало тождеством:

      4m+9+7m2−3m+6m2+6−3+m+m2=0.

      Можно использовать несколько пар скобок. В ответ запишите левую часть равенства с расставленными скобками.

    3. Представьте многочлен

      −7x2+11x−1

      в виде разности двучлена второй степени и двучлена первой степени.

      В ответ запишите разность со скобками.

  6. Умножение одночлена на многочлен. Раскрыть скобки и упростить выражение.
